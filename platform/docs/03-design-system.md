# 03 — نظام التصميم (Design System)

**الاتجاه البصري:** هادئ، محايد، وظيفي — بروح Linear/Stripe/Vercel. الحدود الرفيعة بدل الظلال،
الطباعة القوية بدل الزخرفة، واللون محجوز للمعنى (الحالة) والهوية (التطبيق).

المصدر الوحيد للرموز: `resources/css/tokens.css`. المكوّنات: `resources/js/Components/ui/*`.

## 1. الألوان

|---|---|---|---|

| التطبيق | الرمز | القيمة |
|---|---|---|
| المنصة/النظرة العامة | `--app-platform` | `#5b5bd6` (بنفسجي) |

يُضبط `--accent` على مستوى المساحة (`[data-app="fleet"]`) فتتلون الأزرار الأساسية والعنصر النشط تلقائياً.

### الحالات (دلالية فقط)
| الرمز | المعنى | أمثلة |
|---|---|---|
| `--success` | تم/سليم | معتمدة، إصدار حالي، يعمل |
| `--warning` | يحتاج انتباهاً | بانتظار المراجعة، إصدار قديم، توضيح |
| `--danger` | مشكلة/نهائي سلبي | مرفوضة، متوقفة، خطأ |
| `--info` | معلومة/جارٍ | نشطة، قيد التنفيذ |
| `--neutral` | غير معروف/لا ينطبق | لم يبلّغ، مسودة |

كل حالة لها `-bg` (خلفية شفافة 10–14%) و`-fg` (نص بتباين ≥ 4.5:1) في الوضعين.

## 2. الطباعة

- **العربية:** IBM Plex Sans Arabic (مضمّنة محلياً عبر `@fontsource` — لا اعتماد على CDN في الشبكة الداخلية).
- **اللاتينية والأرقام:** Inter. الأرقام دائماً بخط Inter وأرقام إنجليزية وجدولية (`tabular-nums`) — متوافق مع تفضيل المشروع الحالي للأرقام الإنجليزية.
- **أحادي المسافة:** للمعرفات والأكواد ولوحات المركبات: `ui-monospace`.

| الرمز | الحجم/السطر | الوزن | الاستخدام |
|---|---|---|---|
| `--fs-xs` | 12/16 | 500 | شارات، تسميات صغيرة |
| `--fs-sm` | 13/20 | 400–500 | الجداول، الحقول، الشريط الجانبي |
| `--fs-md` | 14/22 | 400 | النص الأساسي |
| `--fs-lg` | 16/24 | 600 | عناوين الأقسام |
| `--fs-xl` | 20/28 | 600 | عنوان الصفحة |
| `--fs-2xl` | 28/34 | 600 | الأرقام الرئيسية في المؤشرات |

## 3. المسافات والتخطيط

- مقياس 4px: `--s-1`=4 … `--s-8`=32، `--s-10`=40، `--s-12`=48.
- أنصاف أقطار: `--r-sm` 6 (حقول/أزرار)، `--r-md` 8 (بطاقات)، `--r-lg` 12 (أدراج/حوارات).
- ارتفاعات التحكم: 32px افتراضي، 28px مضغوط (أدوات الجداول)، 36px للحقول في النماذج.
- **الهيكل:** شريط تطبيقات 56px + شريط سياقي 232px + محتوى مرن بحد أقصى 1440px. الشريط العلوي 52px.
- **نقاط التوقف:** `≥1280` كامل، `1024–1279` شريط سياقي قابل للطي، `720–1023` درج، `<720` جوال (جداول ← بطاقات).

## 4. الاتجاه واللغة (RTL/LTR)

- `<html lang dir>` يُضبط من الخادم حسب لغة المستخدم (`ar` افتراضياً، `en` اختياري) — كوكي `locale`.
- **خصائص منطقية فقط** في CSS: `margin-inline-start`, `padding-inline-end`, `inset-inline-start`, `border-inline-start`. ممنوع `left/right` في المكوّنات.
- الأيقونات الاتجاهية (أسهم، "التالي") تنعكس بـ `[dir=rtl] .flip { transform: scaleX(-1) }`.
- المحتوى المختلط: أرقام اللوحات والهواتف والإصدارات والمعرفات داخل `<bdi>` أو `dir="ltr"` حتى لا تنقلب.
- التواريخ: `Intl.DateTimeFormat` بلغة الواجهة مع `numberingSystem: 'latn'`.
- النصوص في `lang/ar.json` و`lang/en.json` ودالة `t()` واحدة في Vue.

## 5. المكوّنات

| المكوّن | القرار |
|---|---|
| **الأزرار** | `primary` (لون الهوية، إجراء واحد لكل سياق)، `secondary` (حد)، `ghost` (أدوات)، `danger` (للإجراءات الهدامة فقط). حالة تحميل مع تعطيل. |
| **الحقول** | تسمية فوق الحقل، تلميح تحته، رسالة خطأ بلون الخطر مع `aria-invalid`. حلقة تركيز 2px بلون الهوية. |
| **الجداول** | رأس ثابت بخلفية `--surface-2`، صفوف 44px، حدود أفقية فقط، أرقام بمحاذاة النهاية، الصف قابل للنقر بالكامل عند وجود تفاصيل، ترقيم في التذييل مع العدد الإجمالي. تتحول إلى بطاقات تحت 720px. |
| **شريط الفلاتر** | بحث + فلاتر كأزرار منسدلة مدمجة + "مسح" يظهر فقط عند وجود فلتر نشط. الفلاتر في الـ URL (قابلة للمشاركة والحفظ). |
| **التبويبات** | خط سفلي بلون الهوية، مع عداد اختياري. تستخدم لعرض نفس الكيان بطرق مختلفة فقط. |
| **البطاقات** | للتجميع فقط عند الحاجة — لا بطاقة حول كل شيء. حد 1px بلا ظل. |
| **المؤشرات (KPI)** | رقم كبير + تسمية + سياق ("من 91 بئراً نشطاً") + رابط للإجراء. ممنوع الرقم بلا قرار. |
| **الشارات (Status)** | نقطة + نص، بخلفية الحالة. نص دائماً مع اللون (لا اعتماد على اللون وحده). |
| **الدرج (Drawer)** | للتفاصيل والإجراءات السياقية دون فقد سياق القائمة (مثل تفاصيل الرحلة والقرار). من جهة النهاية، 520px، يغلق بـ Esc. |
| **الحوار (Dialog)** | للتأكيد الهدام فقط، مع نص يشرح العاقبة. |
| **الإشعارات (Toast)** | نجاح/خطأ بعد العمليات، تختفي بعد 5 ثوانٍ، `aria-live="polite"`. |
| **الحالات الفارغة** | أيقونة خافتة + جملة تشرح السبب + إجراء إن وُجد. تمييز "لا توجد بيانات" عن "لا توجد نتائج لهذا الفلتر". |
| **التحميل** | هياكل (skeleton) للجداول والمؤشرات، شريط تقدم علوي لتنقلات Inertia. |
| **المخطط الزمني** | لسجل التدقيق وأحداث الرحلة التقنية: نقطة + وقت + فاعل + وصف. |

## 6. البيانات المرئية

- المخططات فقط حيث يوجد اتجاه يدعم قراراً. الأشرطة الأفقية للتوزيعات (حالات المحابس، إصدارات التطبيق) بـ SVG أصلي بدون مكتبة.
- لون واحد لكل سلسلة من ألوان الحالة أو الهوية، تسميات مباشرة بدل وسيلة إيضاح منفصلة.
- الأرقام في المخطط تُعرض نصاً أيضاً (إتاحة).

## 7. الإتاحة

- تباين نص ≥ 4.5:1 في الوضعين، حلقة تركيز مرئية لكل عنصر تفاعلي.
- التنقل الكامل بلوحة المفاتيح: `⌘K` لوحة الأوامر، `Esc` لإغلاق الدرج/الحوار، `j/k` للتنقل بين صفوف صندوق المراجعة.
- أهداف لمس ≥ 32px (≥ 40px على الجوال).
- الأدوار والأوصاف: `nav[aria-label]`، `aria-current="page"`، جداول بـ `<th scope>`.

## 8. الوضع الداكن

متوفر ويتبع النظام افتراضياً، مع اختيار يدوي يُحفظ في `localStorage.theme` (نفس المفتاح المستخدم في النظام الحالي فيبقى تفضيل المستخدم واحداً). الخرائط تبقي عناصر التحكم فاتحة للوضوح.
